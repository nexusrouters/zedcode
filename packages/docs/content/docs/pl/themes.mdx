# Motywy

ZedCode obsługuje wbudowane motywy oraz własne pliki JSON z motywami.

## Dodaj własny motyw

1. Utwórz katalog motywów:

```bash
mkdir -p ~/.config/zedcode/themes
```

2. Dodaj swój plik JSON do tego katalogu (na przykład `my-theme.json`).
3. Otwórz ZedCode, a następnie przejdź do **Settings -> Theme -> Reload themes**.
4. Wybierz swój motyw z listy rozwijanej. Zostanie zastosowany od razu.

## Lokalizacja motywów

- macOS/Linux: `~/.config/zedcode/themes/`

## Pełna dokumentacja formatu JSON

Skorzystaj z pełnego przewodnika po formacie w dokumentacji głównego repozytorium:

- [`docs/CUSTOM_THEMES.md`](https://github.com/zedcode/zedcode/blob/main/docs/CUSTOM_THEMES.md)
